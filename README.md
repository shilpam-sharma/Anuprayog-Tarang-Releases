# AnuPrayog: Tarang

A scientific data analysis and plotting application.

**Downloads:** see [Releases](https://github.com/shilpam-sharma/Anuprayog-Tarang-Releases/releases) — the Windows
installer is attached to each release.

Free to use, closed source. See the EULA for full terms.

## Citing

If this software contributed to work you are publishing, please cite it.
The application itself offers ready-made citations under
**Help &gt; How to Cite…**, carrying the exact version you ran.

```bibtex
@software{sharma2026anuprayog,
  author  = {Sharma, Shilpam},
  title   = {{AnuPrayog: Tarang}},
  version = {2.6.0.0},

  url     = {https://github.com/shilpam-sharma/Anuprayog-Tarang-Releases},
  note    = {Free to use, closed source. See the EULA for full terms.}
}
```

## What is in this repository

This repository exists so that releases are publicly reachable and
citable. It carries the installer, the release notes, the licence and
the citation metadata. **The source code is not public** — it lives in a
private repository and is not distributed.
